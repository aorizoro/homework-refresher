# homework-refresher

סקיל לקלוד: שולחים קובץ תרגיל בית, ומקבלים רענון קצר של חומר ההרצאה לפני שניגשים לפתור. בלי פתרונות ובלי רמזים.

## התקנה ב-Claude Code
```
/plugin marketplace add aorizoro/homework-refresher
/plugin install homework-refresher@homework-refresher-marketplace
```

## עדכון לגרסה חדשה
```
/plugin marketplace update homework-refresher-marketplace
```

## התקנה ב-claude.ai (ידנית, בלי סנכרון)
מורידים את התיקייה plugins/homework-refresher/skills/homework-refresher, מכווצים ל-ZIP, ומעלים ב-Customize > Skills.
